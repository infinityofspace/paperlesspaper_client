Installation
============

You can either install the package from the Python Package Index (PyPI) using pip:

.. code-block:: bash

   pip3 install paperlesspaper-client


or you can install the package from the source code:

.. code-block:: bash

   git clone https://github.com/infinityofspace/paperlesspaper_client.git
   cd paperlesspaper_client
   pip3 install .
